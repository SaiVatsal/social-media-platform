# PULSE // Next-Gen Social Sphere

A modern, high-engagement social media platform built with React, Vite, Tailwind CSS, and Zustand, simulating Firebase Firestore real-time feed updates and cloud fan-out.

## ✨ Features
- **Algorithmic Audio-Visual Feed**: Rich multimedia posts with likes, threaded comments, shares, and moderation flags.
- **24-Hour Expiring Stories**: Interactive story tray with real-time countdowns and visual rings.
- **Direct Messaging Hub**: Live interactive conversation view with active status indicator.
- **Community Gatherings & RSVPs**: Interactive event calendar with instant RSVP confirmations.
- **Follow Suggestions**: Personalized friend recommendations with mutual connections.
- **Content Moderation Engine**: Report and flag suspicious posts for review.
- **AI Avatar Synthesizer**: Simulated AI avatar generator for profile customization.

## 🚀 Quickstart
```bash
npm install
npm run dev
```

## 🎨 Design System
- **Palette**: Neon purple to magenta gradient, deep obsidian (`#0f0728`), electric pink accents.
- **Typography**: Plus Jakarta Sans.
